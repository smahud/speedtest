# legacy/

Script lama yang **tidak dipakai** oleh installer saat ini (tidak ada di
MANIFEST / tidak ikut disinkronkan ke server).

- `serverinstall.sh` — versi awal: hardcode `/root`, `source /root/data.ini`
  (rawan eksekusi kode), menulis `/etc/rc.local`, dan berisi placeholder
  hadiah/nomor telepon di output.

Disimpan hanya sebagai arsip. Jangan dijalankan di server produksi.
